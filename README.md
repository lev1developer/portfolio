# Meu Portfólio Interativo

Este é o meu portfólio pessoal, criado para apresentar um pouco de quem eu sou, o que venho estudando e para onde quero levar minha carreira na tecnologia.

Estou no começo da minha jornada como desenvolvedor, com foco em **back-end**. Tenho estudado principalmente Python e lógica de programação, e uso projetos como este para aprender na prática, testar ideias e acompanhar minha própria evolução.

A ideia deste portfólio foi fugir um pouco de uma página tradicional: em vez de apenas listar informações, criei um **mapa de conhecimento interativo em 3D**, onde cada ponto representa uma parte da minha trajetória.

## O que você encontra por aqui

- **Mapa de conhecimento 3D:** uma visualização interativa das minhas áreas de interesse, habilidades e projetos.
- **Busca:** permite localizar áreas e tópicos dentro do mapa.
- **Painel de detalhes:** ao selecionar um ponto, é possível explorar informações relacionadas.
- **Trajetória:** um resumo do que estou fazendo agora e dos próximos passos que quero seguir.
- **Contato:** links para falar comigo e acompanhar meus estudos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES Modules)
- [Three.js](https://threejs.org/) para a visualização 3D
- Git e GitHub para versionamento e publicação

O Three.js é carregado por CDN, então é necessário ter conexão com a internet para carregar a parte 3D.

## Como executar localmente

Como o projeto utiliza módulos JavaScript, o ideal é abrir com um servidor local em vez de abrir o HTML diretamente pelo navegador.

1. Baixe ou clone este repositório.
2. Deixe os arquivos `index.html`, `style.css` e `script.js` na mesma pasta.
3. Abra o terminal nessa pasta.
4. Inicie um servidor local:

```bash
python -m http.server 8000
```

5. Acesse no navegador:

```text
http://localhost:8000
```

> **Observação:** o arquivo `style.css` também precisa estar na pasta. Se estiver usando uma versão do projeto que ainda não contém esse arquivo, adicione a folha de estilos antes de executar.

## Controles do mapa

- Arraste para girar a visualização.
- Use `Shift` + arraste para mover o mapa.
- Use a roda do mouse para aproximar ou afastar.
- Clique nos pontos para ver mais informações.
- Use os controles na tela para dar zoom ou centralizar a visualização.

Se o navegador ou dispositivo não oferecer suporte ao WebGL, o projeto mantém atalhos alternativos para acessar as informações.
